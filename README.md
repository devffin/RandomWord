# RandomWord

RandomWord is a small Windows desktop app that displays a randomly selected word each time you open it.

## Usage

Run `RandomWord.exe` to open the app. A window will show a random word; click **OK** to close it.

The app reads `words.txt` from its working directory. When launching the executable directly, keep `words.txt` beside it.
